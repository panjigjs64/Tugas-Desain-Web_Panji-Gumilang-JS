# FundFlow - Simulasi Keuangan Mahasiswa

## 📌 Deskripsi
FundFlow adalah aplikasi web simulasi keuangan yang dirancang untuk membantu mahasiswa mengelola keuangan, mencatat pengeluaran, dan merencanakan tujuan finansial secara realistis.
